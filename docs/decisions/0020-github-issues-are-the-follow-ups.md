# 0020. GitHub issues are the list of follow-ups

**Date:** 24 November 2026
**Issues/PRs:** PR #64, PR #113

## Decision

A limit, a doubt or an improvement is never left only in a chat or a code
comment. It is drafted in `scratch/<topic>-issues.md`, checked with
`scratch/make_issues.py`, and filed when the owner says so. What is open is
read from GitHub. A pull request has labels and a milestone. See
[pull requests and follow-ups](../pull-requests-and-follow-ups.md).

## Why

Follow-ups in chats and comments are lost; GitHub keeps them in one list.
